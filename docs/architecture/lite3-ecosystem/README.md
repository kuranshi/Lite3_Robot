# Lite3 五仓库架构图

本目录保存模型、训练和部署仓库的交互架构分析，独立于后续开发代码。

## 查看

- 下载 `lite3-ecosystem.html` 后用浏览器打开；这是独立 HTML 文件，无需构建。
- GitHub 文件页显示 HTML 源码，不能直接运行交互图。
- [源码索引](sources.md)包含五个仓库固定提交的 GitHub 链接。

## 内容与结论

图中以 Lite3 为主线，覆盖 `deep_robotics_model`、`rl_training`、`sdk_deploy`、`Lite3_rl_deploy` 和 `Lite3_MotionSDK`。

- 模型资源供 Isaac Lab 训练使用，训练策略导出为 ONNX 后交接给部署代码。
- ROS2 部署通过 `lite3_transfer` 桥接 UDP；另一条路径通过 MotionSDK 接口直接接入 Lite3。它们是替代路径。
- 已读版本的训练默认关节姿态为每腿 `[0, -0.65, 1.3]`，快速导出元数据及部署代码为 `[0, -0.8, 1.6]`。使用具体策略前需对齐实际训练配置。
- 文档分析不代表当前机器人运行状态，未启动训练或机器人控制。

## 文件边界

本目录仅存放架构图、源码索引、说明及图形运行时许可文件。后续训练、部署、SDK 或应用源码应放在本目录之外。

HTML 内的源码证据来自生成时的本地跨仓库快照；可移植的原始仓库入口以 `sources.md` 为准。未上传本地源码快照、Git 元数据或机器相关验证回执。
